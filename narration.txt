HOW TO PRODUCE THE AUDIO
------------------------
Easiest path (ElevenLabs):
  1. Paste the text column into the ElevenLabs speech editor.
  2. For the two hard words use their pronunciation field, or edit by hand:
       Hopf        -> "hopf"     (IPA: hɔpf)
       Villarceau  -> "VEE-yar-soh" (IPA: vijɑʁso)
  3. Export one WAV, then go to ASSEMBLY step 2.

Fully offline, no account, no key (Piper or espeak-ng):
  1. Split this file into one .txt per line.
  2. Synthesize each line:
       piper -m en_US-lessoc-medium -f 001.txt -w 001.wav
     or, with nothing installed:
       espeak-ng -v en-us -w 001.wav -f 001.txt
  3. Pad each line with its pause, then concat in numeric order. This script
     does both for you:
       python build_narration.py --assemble
     (requires ffmpeg on PATH; writes padded/ and voice_timed.wav)

Mixed engines are fine. Azure Speech, Google Cloud TTS, OpenAI TTS, PlayHT,
Kokoro, macOS `say -o line.wav "text"`, or even a phone recording all work.

ASSEMBLY
--------
Step 1. Render the movie (silent):
    manim render scene.py HopfFibrationScene

Step 2. Get the audio onto the pause grid. Either run the helper:
    python build_narration.py --assemble
  or, if you already have one continuous WAV of just the spoken lines, cut it
  into the 103 segments and rebuild it with ffmpeg per the helper's
  generated commands.

Step 3. Mux audio onto the movie:
    ffmpeg -i media/videos/scene/1440p60/HopfFibrationScene.mp4 \
      -i voice_timed.wav -c:v copy -c:a aac -b:a 192k -shortest \
      hopf_fibration_final.mp4

Step 4. Optional, loudness normalize to YouTube's -14 LUFS:
    ffmpeg -i hopf_fibration_final.mp4 -af loudnorm=I=-14:TP=-1.5:LRA=11 \
      -c:v copy hopf_fibration_final_ln.mp4

Subtitles are a separate, optional job and are NOT part of this file. The line
numbers here are stable, so you can generate an SRT straight from them and burn
it in later with:
    ffmpeg -i hopf_fibration_final.mp4 -vf "subtitles=hopf.srt" -c:a copy out.mp4
